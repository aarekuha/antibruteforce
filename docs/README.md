## Конфигурация

Скопировать `config.example.yaml` в `config.yaml` и задать `hmac_secret`. Для переопределения настроек при запуске использовать переменные `ABF_*`, указанные в шаблоне. Для длительностей указывать единицу времени, например `500ms` или `5s`.

В разделе `redis` задать адрес, пароль, число свободных соединений (`max_idle`), срок их хранения (`idle_timeout`) и таймауты подключения, чтения и записи.
